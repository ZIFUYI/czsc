# 000905 与 159915 纯日线 CTA 优化记录

## 目标

在此前 `000852.XSHG` 纯日线 CTA 策略基础上，对 `000905.XSHG` 与 `159915.XSHE` 做分标的参数优化，目标仍为：

- 回测区间：`2020-01-01` 至 `2026-05-29`
- 年化收益不低于 `20%`
- 最大回撤控制在 `10%` 以内
- 仅使用日线 OHLCV
- 当日收盘生成目标仓位，下一交易日 close-to-close 收益使用前一日仓位
- 手续费：单边 `0.0002`
