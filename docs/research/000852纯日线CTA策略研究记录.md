# 000852 纯日线 CTA 策略研究记录

## 目标

- 标的：`000852.XSHG`
- 回测区间：`2020-01-01` 至 `2026-05-29`
- 策略频率：纯日线，所有信号只使用日线 OHLCV
- 收益口径：每日收盘生成目标仓位，下一交易日 close-to-close 收益使用前一日仓位
- 目标：年化收益不低于 `20%`，最大回撤控制在 `10%` 以内
- 手续费：单边 `0.0002`

## 策略逻辑

策略使用 5 个日线 CTA 方向腿取平均，再按 30 日实现波动率做目标仓位缩放。

| 方向腿 | 规则 | 说明 |
|---|---|---|
| `MA_H_N3_B50` | 收盘价相对 3 日 SMA 偏离超过 `50BP` 后顺势持有 | 短周期顺势 |
| `MA_R_N20_B500` | 收盘价相对 20 日 SMA 偏离超过 `500BP` 后反向持有 | 中周期反转 |
| `MOM_R_N20_B1500` | 20 日动量超过 `1500BP` 后反向持有 | 中周期动量反转 |
| `MA_H_N50_B100` | 收盘价相对 50 日 SMA 偏离超过 `100BP` 后顺势持有 | 中周期趋势 |
| `DON_F_N320` | 突破前 320 日高低点时做多 / 做空，否则空仓 | 长周期突破 |

仓位计算：

```text
score_avg = mean(5 legs)
leverage = min(0.40 / realized_vol_30d, 4.0)
weight = score_avg * leverage
```

其中 `realized_vol_30d` 为日收益 30 日滚动年化波动率。

## 结论

该纯日线 CTA 策略在目标区间内达到 `20%` 年化收益和 `10%` 最大回撤约束：年化收益 `38.03%`，最大回撤 `-9.13%`。

需要注意，该结果使用日线信号和日线收益，但允许波动率目标仓位带来最高约 `3.78` 倍名义仓位，适合按股指期货 / 掉期等可杠杆工具理解；若限定现货 1 倍仓位，当前简单日线规则未找到满足同一目标的组合。
