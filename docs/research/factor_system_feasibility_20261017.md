# 因子评价、准入与组合体系可行性实验（2026-10-17，修正版）

**结论：当前版本尚未获得整套经济可行性的充分证据。组合与排序在广域日线有局部正向迹象，值得保留；正式准入持续为空，无法证明完整链路可以产生有增量价值的组合。** 这既不等于方法必然无效，也不等于流程跑通就已经有效。

本报告以修正版目录为准。原五轮结果、上一轮最小对照、本轮发现版均保留。全程未按测试收益更换候选、调整门槛或搜索最优参数。代码只修正一处影响实验有效性的原生信号起点，另补一个针对该问题的回归测试；没有增加框架、接口或部署设计。

**1. 纠正了什么**

上一轮等先验=1与配权上限=1重合，正向表现不能上调原始系数。保持原64个因子—资产成员不变，诊断先验改为0.5后，上下倾斜都实际发生。原等权和原prior=1账本精确复现；2bp净收益依次为等权−1.0011%、旧配权−1.0471%、纠正配权−1.1108%。纠正设定没有带来收益提升，且差异区间跨零。此项只解释旧控制，不用它代表修正版整链路。

新的简单基线采用训练期完整事件N≥30且扣费后算术平均事件收益>0的全部候选，等权，空集持有现金，不再强迫前四分之一中负均值候选入选。另设同一正均值且有效样本充分的候选池、同一入选数量的均值排序／Q排序对照，避免数量与负均值混入造成混淆。

物理截断验证又发现既有研究入口把原生信号起点写死为2020年，完整长历史中2016—2019的相关输入被填成默认值；截断到2019后却出现实际信号，AC01L在000016上有137/975个历史权重不同。已在 [hypothesis_bank.py](/Users/chenqiang/Desktop/czsc/examples/alpha_mining_agent/hypothesis_bank.py):998 将既有Rust生成器的sdt调用参数改为首根预热K线时间；核心算法未变。旧报告与发现版的长历史推断受该问题影响，不作为本报告主证据。修正版单独重跑了完整实验。

**2. 范围与事前固定规则**

- 长历史权益：原来的8条日线参考价格（7指数＋1 ETF），2015预热、2016起计算候选。2016—2019训练→2020—2021检验；2016—2021→2022—2023；2016—2023→2024—2026-05-29。共1550个非重叠检验交易日。
- 广域日线：覆盖完整的41商品连续价格＋上述8权益参考，共49条。2020预热、2021起计算候选；分别在2023、2024、2025年末冻结成员，检验2024、2025、2026至5月28日，共579日。ni只因缺2022-03-10排除，其他8个被排除商品因历史起点晚；没有按收益选资产。
- 61个已注册日线候选、六簇、多空方向；共10,431次候选—资产—时段检查。不是10,431个独立假设或样本，两个数据组也有交集。
- 10组对照逐层区分简单筛选、Q初筛、本地执行门禁、完整准入、完整合成、固定成员滚动配权、固定数量排序和现金。完整准入使用现有execution＋pooled＋smoothness三门禁，完整合成实际调用正式资产内合成和跨资产分配路径。
- 统一初始资金、次日开盘执行、每段平仓起步及末日收盘清算；每次按实际成交数量收费。单边费用0/2/4/7/12bp均冻结成员与持仓。所有臂共用1倍总敞口上限；不分配的资金留现金。
- 风险匹配只用各段训练数据拟合≤1的固定缩放，零组合不参与最小正波动率标定。该回填训练收益只用于校准，不当成历史可交易业绩。
- 同日组合收益差在各段内部进行10/20/40日循环块重采样，主块长20日、5000次；4个主比较×2组，个别区间为99.375%，采用Bonferroni名义5%族错误率口径；实际区间覆盖依赖块重采样假设。其他费用、风险匹配与排序对照是敏感性或次要分析。高置信尾部只有约16个抽样点，区间尾部精度有限。

样本已在前轮接触过，本轮属于探索性时间验证，不是全新盲测。权益参考不能直接视为可双向交易资产，连续期货价格也尚未纳入真实换月、保证金和合约乘数约束。本轮验证日线方法，不外推到日内或全部多周期共振。

**4. 准入为什么没有形成正式组合**

累计1001次检查满足N≥30，425次满足有效样本要求，6次通过正Q置信下界初筛，4次通过本地执行门禁，完整准入0。计数包含同一候选在不同资产和时段的重复评估。4个本地通过项为权益末段000852/CC02L，以及广域2026段eb/CC01L、sc/CC01L、hc/EC02L；都未通过池化门禁，参数平原检查因前置不通过而未执行，不能记成参数平原本身失败。

必须区分三类原因：

- **检验条件不足**：8权益不能满足Tier1跨市场条件；49广域满足Tier1规模和资产类别，但贵金属Tier2只有2资产，且所有Tier3缺真实微结构分组。每段权益280/488、广域346/2989次检查在池配置层面不具备条件。
- **事件证据不足**：所有池配置合格的检查仍至少有池成员缺有效事件或三态支持。现有池化规则要求池内任一资产缺支持即全池失败，不只是要求60%或75%资产为正。足够多的K线不等于足够多的独立完整事件。
- **经济／统计证据不足**：四个本地通过项也未达到各自池的普适率与时间块t要求。例如000852/CC02L的权益池普适率25%低于75%；eb/sc对应能源化工池为16.7%低于65%；hc对应跨市场池为12.2%低于60%。这些原因与样本不足可同时出现。

所以不能将全部零准入归咎于样本，也不能把缺检验条件解释成因子已被证伪。当前候选供给、适用域和准入要求尚未形成可实际输出组合的闭环；本轮没有通过删除失败池成员或放松阈值制造通过结果。

**6. 证据可靠性与剩余限制**

原始数据物理截断重算的四组检查均通过，共6,295,871个候选历史权重逐值相同；两组测试期前缀的滚动系数、资产内组合及跨资产持仓也一致。修正版49广域帧的8,447,208个单元格与发现版相同，确认信号起点修复未改变该组数据。针对起点错误的回归在旧函数上失败、修正版通过，连同相关回归共34项通过。

独立审核重新核对123,494个训练事件、全部425个充分样本Q bootstrap、门禁合取及成员名单；600份账本共4,094,200个资产记账点用q=w/p独立复算，最大净收益差2.08e−17。风险校准按训练截止核验；完整合成的校准重建复用了现有合成器，量价账本和波动计算独立。

还发现完整组合的日线尺度问题：[synthesis_engine.py](/Users/chenqiang/Desktop/czsc/examples/multi_factor_cta/synthesis_engine.py):589 对1d回退为16根/日，实际使用240根日线波动窗口、80根日线ER窗口，波动年化倍率约为标准日线的3.92倍。它不是前视问题，但会改变战术路径仓位和滞回触发。已确认部分实际路径受到影响；不能据当前表现否定组合理论，也不能把观察到的改善归因于一个单位口径完全正确的实现。本轮保留冻结参数，未做替代收益调参；下一步应先做这处最小正确性修复再重复同成员对照。

**7. 对目标的判断与下一步**

评价方面，Q排序有局部改善但缺跨范围、风险匹配的一致证据；严格Q初筛也没有稳定优于简单正均值筛选。准入方面，当前规则在现有候选上没有产出正式组合，是整链路验证的直接阻塞。组合方面，广域组存在值得继续验证的正向迹象，尚未同时满足显著增量、风险匹配稳定性和完整门禁要求。

因此当前完成状态是：**已完成一次可以定位瓶颈的可行性实验，尚未完成整套体系可行性的证明。** 下一轮应继续最小验证：先修正日线尺度并冻结同成员重跑；再在看测试结果前明确各类因子的适用域及可检验样本要求，区分“证据不足”和“证据反对”，检验现行全池支持要求是否符合所声称的普适性。不能单纯降门槛求通过。若形成非空正式组合，再用未参与本轮调整的数据验证全链路。暂时没有证据支持投入更多框架工程化。
