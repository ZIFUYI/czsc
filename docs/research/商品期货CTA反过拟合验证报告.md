# 商品期货 CTA 反过拟合验证报告

## 1. 验证对象

验证对象为 `examples/signals_dev/backtest_commodity_futures_cta_main_continuous.py` 中的商品期货主力连续合约 CTA 策略，默认 `signal_style=optimized`。

样本区间：2020-01-01 至 2026-05-29。

基础样本内结果：

| 指标 | 数值 |
|---|---:|
| 年化收益 | 40.23% |
| 最大回撤 | -9.80% |
| 最终净值 | 8.7247 |
| Calmar | 4.11 |
| Sharpe | 2.89 |

## 2. 验证方法

验证脚本：

`examples/signals_dev/validate_commodity_futures_cta_anti_overfit.py`

输出目录：

`examples/results/commodity_futures_cta_main_continuous/anti_overfit_validation/`

本次验证包含三类检查：

1. Walk-forward 样本外验证：每一折只用训练期数据筛选规则，再在下一年度测试。
2. 参数扰动测试：扰动窗口、单腿波动率目标、组合波动率目标、组合杠杆上限、总敞口上限。
3. 留一压力测试：分别剔除一个策略腿、剔除一个年度，观察结果稳定性。

## 3. 验证结果

### 3.1 汇总

| 检查项 | 样本数 | 达标比例 | 最低年化 | 中位年化 | 最差回撤 |
|---|---:|---:|---:|---:|---:|
| 样本内基准 | 1 | 100.00% | 40.23% | 40.23% | -9.80% |
| Walk-forward 样本外 | 4 | 25.00% | -1.23% | -0.79% | -11.54% |
| 参数扰动 | 34 | 67.65% | 28.45% | 39.04% | -12.87% |
| 留一策略腿 | 7 | 28.57% | 37.59% | 39.22% | -11.55% |
| 留一年度 | 7 | 100.00% | 27.99% | 34.75% | -9.80% |

### 3.2 Walk-forward 样本外

Walk-forward 是最关键的反过拟合验证。结果显示，4 个样本外年份/阶段中只有 1 个达到年化 20% 且回撤 10% 以下。

| 测试期 | 样本外年化 | 样本外最大回撤 | 是否达标 |
|---|---:|---:|---:|
| 2023 | -0.94% | -10.20% | 否 |
| 2024 | 20.23% | -5.65% | 是 |
| 2025 | -1.23% | -10.99% | 否 |
| 2026-01-01 至 2026-05-29 | -0.65% | -11.54% | 否 |

这说明：如果严格要求“规则由训练期产生，下一期完全样本外测试”，当前优化流程不能证明策略稳健。

### 3.3 参数扰动

参数扰动整体表现尚可，34 个扰动场景中 23 个达标，达标比例 67.65%。但有多个窗口扰动会把最大回撤推到 10% 以下：

| 场景 | 年化 | 最大回撤 | 是否达标 |
|---|---:|---:|---:|
| 全部窗口 x0.8 | 28.45% | -12.87% | 否 |
| 全部窗口 x0.9 | 30.72% | -12.01% | 否 |
| LPG 腿窗口 x0.8 | 35.00% | -11.23% | 否 |
| 锡腿窗口 x0.8 | 37.62% | -10.99% | 否 |
| 黄金腿窗口 x0.8 | 37.31% | -10.59% | 否 |

这说明：收益并非完全依赖单点参数，但 10% 回撤约束对窗口扰动较敏感。

### 3.4 留一压力测试

留一年度全部达标，说明样本内收益不是完全由某一年贡献。

但留一策略腿只有 2/7 达标，说明当前组合对部分腿的依赖较强。剔除黄金、沪铅、沪锡、生猪、合成橡胶后，最大回撤都会超过 10%。

| 剔除腿 | 年化 | 最大回撤 | 是否达标 |
|---|---:|---:|---:|
| 黄金趋势腿 | 38.39% | -11.55% | 否 |
| 沪铅反转腿 | 39.58% | -11.24% | 否 |
| 沪锡趋势腿 | 39.22% | -10.95% | 否 |
| 生猪趋势腿 | 40.39% | -10.42% | 否 |
| 合成橡胶趋势腿 | 41.02% | -10.39% | 否 |
| 鸡蛋反转腿 | 38.49% | -9.73% | 是 |
| LPG 反转腿 | 37.59% | -9.57% | 是 |

## 4. 结论

当前优化策略的样本内结果达到了“年化 20% 以上、最大回撤 10% 以下”的目标，但反过拟合验证不通过。

主要证据：

- Walk-forward 样本外达标比例只有 25%；
- 样本外 2023、2025、2026 阶段收益接近 0 或为负；
- 留一策略腿达标比例只有 28.57%，说明组合对特定腿依赖较强；
- 参数扰动虽然多数仍有较高收益，但最大回撤对窗口变化敏感。

因此，当前版本应定义为“样本内优化候选”，不应定义为稳健可上线版本。

## 5. 后续建议

下一步应停止围绕当前 7 条腿继续加码优化，改为重新设计更保守的训练流程：

1. 固定候选规则族，使用 walk-forward 训练期选择，禁止使用测试期表现选腿。
2. 目标从“全样本年化 20%、回撤 10%”改为“样本外多数年份为正、组合回撤稳定低于 12%”。
3. 使用更粗粒度、更少参数的规则族，减少单品种单窗口依赖。
4. 对主力连续数据补充真实换月、保证金、合约乘数和滑点压力测试。
