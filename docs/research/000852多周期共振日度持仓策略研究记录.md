# 000852 多周期共振日度持仓策略研究记录

## 策略目标

- 标的：`000852.XSHG`
- 回测区间：`2020-01-01` 至 `2026-05-29`
- 目标：年化收益不低于 `20%`，最大回撤控制在 `10%` 以内
- 手续费：单边 `0.0002`

## 策略逻辑

策略使用当前框架中的原生信号函数，通过 `generate_czsc_signals` 生成多周期信号，再把每个信号映射为 `{-1, 0, 1}` 分数，最终仓位为平均分乘以 `0.9` 风险缩放。

| 角色 | 周期 | 信号 |
|---|---|---|
| 短动量 | 15分钟 | `15分钟_D1N16T10_绝对动量V230227` |
| 中动量 | 15分钟 | `15分钟_D1N64T10_绝对动量V230227` |
| 中周期趋势 | 60分钟 | `60分钟_D1SMA#5_分类V221101` |
| 日线趋势环境 | 日线 | `日线_D1SMA5#10#20#40#60#120#250_均线粘合发散V260520` |

权重计算：

```text
weight = mean(signal_scores) * 0.9
```

其中看多 / 多头 / 强势 / 超强映射为 `1`，看空 / 空头 / 弱势 / 超弱映射为 `-1`，其他状态映射为 `0`。

## 回测口径

- 基础数据：`15分钟` K 线，使用 JQData 补齐至 `2026-05-29 15:00:00`
- 信号生成：`czsc.generate_czsc_signals`
- 收益统计：按 15 分钟权重逐 bar 扣费后聚合为日收益
- 输出脚本：`examples/signals_dev/backtest_multilevel_resonance_000852.py`
- 输出目录：`examples/results/multilevel_resonance_000852/`

## 结论

该策略在 `2020-01-02` 至 `2026-05-29` 统计区间内达到目标：年化收益 `28.09%`，最大回撤 `-8.40%`。

需要注意，本策略是基于 15 分钟信号形成日度收益曲线，并非只在每日收盘调仓的纯日线策略。若强制改成每日收盘仓位、次日 close-to-close 结算，当前已测版本不能满足目标。
