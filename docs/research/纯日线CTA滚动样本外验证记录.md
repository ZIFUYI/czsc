# 纯日线 CTA 滚动样本外验证记录

## 验证目的

对前面针对 `000852.XSHG`、`000905.XSHG`、`159915.XSHE` 做出的纯日线 CTA 优化结果进行防过拟合验证。

验证方式不再使用全样本最优参数，而是 walk-forward：

| 训练期 | 测试期 |
|---|---|
| 2016-2019 | 2020 |
| 2017-2020 | 2021 |
| 2018-2021 | 2022 |
| 2019-2022 | 2023 |
| 2020-2023 | 2024 |
| 2021-2024 | 2025 |
| 2022-2025 | 2026-05-29 |

每一折只允许用训练期选择参数，测试期参数冻结。三标的分别独立选择参数并测试。

## 选择规则

候选信号库：

- 日线 MA 偏离：顺势 / 反转 / 空仓模式
- 日线动量：顺势 / 反转 / 空仓模式
- 日线 EMA 交叉
- 日线 Donchian 突破
- 组合方式：单腿、AVG 组合、VOTE 组合
- 风险缩放：滚动年化波动率目标仓位

训练期筛选约束：

- 年化收益不低于 `15%`
- 最大回撤不超过 `12%`
- 亏损年份不超过 `1`
- 最大绝对仓位不超过 `3`
- 换手低于候选池 80% 分位

若某折没有候选满足约束，则退回到较宽松候选池中按综合分数选择。

## 结论

严格 walk-forward 验证没有通过。

- `000852.XSHG` 样本外为正，但年化只有 `10.31%`，最大回撤 `-15.22%`，低于原目标。
- `000905.XSHG` 与 `159915.XSHE` 样本外均为负收益，且回撤显著放大。
- 这说明此前全样本优化得到的 `20% / -10%` 结果存在明显样本内适配风险。

后续不建议继续直接加大参数搜索。更合理的方向是：

1. 降低目标，从单标的 `20% / -10%` 改为样本外 Calmar 与组合稳健性优先；
2. 固定少数经济含义清晰的信号结构，只优化风险预算；
3. 做三标的组合层面验证，而不是要求每个标的单独全程达标；
4. 使用更长样本或留出完全不参与研究的最终验证集。
