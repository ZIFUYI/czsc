# 机构级量化策略架构与研发工作流 (Quant Strategy Architect)

当用户提出任何交易策略需求或主观交易想法时，严格遵循本项目标准指南 [`docs/strategy_development_guide.md`](file:///d:/czsc/docs/strategy_development_guide.md)。

---

## 必执行动作：四步反向质询与对齐

在编写任何策略代码前，Agent 必须首先审查或向用户确认以下四个关键边界：

1. **交易工具属性**：
   - 是否为 ETF 期权 / 日内 T+0 品种？
   - 若涉及期权或日内交易，**必须强制配置 14:45 停止开仓，14:55 准时全部市价强平**，彻底阻断隔夜 Theta 时间价值衰减与跳空归零风险。
2. **多空对称性**：
   - 规则是否包含对称的做空状态机？
   - 严禁单向做多抄底。必须构建对称的做空机制以抵御单边大熊市。
3. **结构证伪止损点**：
   - 严禁使用固定百分比止损（如 1%）。
   - 止损必须精确锚定在形态破位点（多头锚定回踩次低点或形态低点，空头锚定反弹次高点）。
4. **动态追踪止盈**：
   - 必须配置 `sl_threshold = 1.2% ~ 1.5%` 的极值动态追踪止盈，确保单笔盈亏比 $\ge 1.7$。

## 核心开发步骤 (SOP)

1. **阅读标准规范**：
   查阅 [`docs/strategy_development_guide.md`](file:///d:/czsc/docs/strategy_development_guide.md) 获取标准状态机模板与验收指标卡。
2. **两阶段状态机建模**：
   - 阶段 1 (Setup)：蓄力势能拉偏（连续下跌/连续远离均线）；
   - 阶段 2 (Confirmation)：微观反包吞噬（$C \ge \max(H_{t-1}, H_{t-2})$）、高低点抬高、突破枢纽点。
3. **真实高频行情驱动与全品种池准入（Full-60 Only）**：
   - 严禁使用带自回归正向漂移的 Mock 数据。
   - 接入天勤等真实 5m/分钟级全量历史数据（必须覆盖 2020 宽幅牛、2022 单边熊、2023 慢熊等极端周期）。
   - **废弃 `Core-20`，统一使用 `Full-60`**：商品期货多因子 CTA 因子挖掘、池化准入与组合验证一律直接在 **`Full-60`（60 品种全池）** 上进行，不再单独测试早期摸索阶段的 `Core-20`（20 品种子集）。
4. **双引擎交叉对齐**：
   - 核心组件：`from czsc import WeightBacktest`
   - 与 Backtrader 订单流双向对齐，夏普比率、最大回撤、逐年收益率误差控制在 5% 以内。
5. **指标卡终审验收**：
   - 夏普 $\ge 1.5$ (行业优秀 $\ge 2.0$)
   - 单笔盈亏比 $\ge 1.5$ (行业顶级 $\ge 1.8$)
   - 最大回撤 $\le 12\%$
   - 年胜率 $\ge 80\%$
